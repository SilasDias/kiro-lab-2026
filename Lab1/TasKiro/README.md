# Lab 1 — TasKiro (Kiro Workshop)

## O que é
Protótipo de gerenciador de tarefas construído com Kiro (AWS) usando
o paradigma spec-driven development.

## Stack
- HTML5 (sem frameworks)
- Tailwind CSS (Play CDN)
- Lucide Icons (CDN)
- localStorage para persistência

## Features implementadas
- CRUD completo de tarefas
- Filtros (Todas/Hoje/Próximas/Favoritas/Concluídas)
- Criação de projetos com cores
- Busca em tempo real
- Drag & drop para reordenar
- Tema claro/escuro
- Modal de confirmação para exclusão
- Toasts de feedback
- Responsivo (mobile-first)
- Ocultação robusta de camadas (pointer-events: none)
